# برونت كمبيوتر — الموقع والمتجر الإلكتروني (الإصدار 3.0)

إعادة بناء كاملة لموقع ومتجر **برونت كمبيوتر (ProNet Computer)** على أساس حديث وآمن،
بعد فحص النسخة القديمة (ملف HTML واحد بحجم 1.37 MB) التي كانت تعاني من ثغرات أمنية
ومشاكل في الأداء وSEO والوصولية.

---

## المكدّس التقني

| الطبقة | التقنية |
| --- | --- |
| إطار العمل | Next.js 15 (App Router) + React 19 |
| اللغة | TypeScript (وضع صارم) |
| التنسيق | Tailwind CSS v4 — **بناء مسبق بدون CDN** |
| قاعدة البيانات | `node:sqlite` (مدمجة في Node 22.5+) — بلا اعتماديات أصلية |
| تجزئة كلمات المرور | `scrypt` من `node:crypto` |
| الجلسات | رموز عشوائية مُخزَّنة في قاعدة البيانات + كوكي `HttpOnly` |
| الخطوط | Cairo عبر `next/font` (يُستضاف محليًا) |

---

## التشغيل

```bash
# 1) تفعيل Node في المسار (على ويندوز إن لم يكن في PATH)
#    أو استخدم المسار الكامل:  "C:\Program Files\nodejs\npm.cmd"

# 2) تثبيت الاعتماديات
npm install

# 3) التطوير
npm run dev            # http://localhost:3000

# 4) الإنتاج
npm run build
npm run start

# أدوات مساعدة
npm run typecheck      # فحص الأنواع دون بناء
npm run reset-db       # حذف قاعدة البيانات وإعادة التهيئة (يحذف كل البيانات!)
```

عند أول تشغيل تُنشأ قاعدة البيانات `data/pronet.db` وتُبذَر البيانات تلقائيًا،
وتُطبع بيانات الدخول الأولية في الطرفية وفي الملف `data/INITIAL_CREDENTIALS.txt`.

> **مهم:** غيّر كلمات المرور من لوحة التحكم فورًا، ثم احذف ملف `INITIAL_CREDENTIALS.txt`.

### متغيرات البيئة (اختيارية) — `.env.local`

```env
# عنوان الموقع العام (يُستخدم في SEO وsitemap وJSON-LD)
PRONET_SITE_URL=https://pronet-computer.com

# مسار بديل لقاعدة البيانات
PRONET_DB_PATH=./data/pronet.db

# لضبط كلمة مرور موحّدة لكل حسابات البذر (بدل توليد كلمات مرور عشوائية)
PRONET_SEED_ADMIN_PASSWORD=
```

## ما الذي أُصلح مقارنةً بالنسخة القديمة

### الأمن
| الثغرة في النسخة القديمة | الحل في النسخة الجديدة |
| --- | --- |
| دخول بضغطة واحدة بدون كلمة مرور (`quickLoginAsRole`) | حُذف نهائيًا — لا يوجد أي مسار دخول بلا كلمة مرور |
| كلمة مرور `pronet2026` نصًّا صريحًا داخل الـHTML | كلمات مرور عشوائية مُجزَّأة بـ scrypt |
| الطلبات تُحفظ في `localStorage` عند العميل فقط | تُحفظ في SQLite على الخادم وتصل للإدارة فعليًا |
| رمز GitHub مكشوف في المتصفح | حُذف من الواجهة نهائيًا |
| تغيير حالة الطلب من المتصفح بلا تحقق | Server Action يتحقق من الجلسة والصلاحية على الخادم |
| لا تحقق من مدخلات الطلب | تحقق كامل + **إعادة حساب الأسعار من قاعدة البيانات** |
| لا حماية من الإغراق | محدّد معدّل: 10 طلبات/10 دقائق، و6 محاولات دخول/10 دقائق |
| لا ترويسات أمنية | CSP + X-Frame-Options + nosniff + Referrer-Policy + Permissions-Policy |

### الأداء
- كانت الصور Base64 مضمّنة داخل الـHTML: **959,164 حرفًا (70.1% من الملف)** منها 510,424 حرفًا مكرّرًا (الشعار 6 مرات).
- أصبحت الصور ملفات منفصلة يخدمها Next.js مع صيغ AVIF/WebP وتحسين تلقائي.
- كود JavaScript المكرّر (سكربت مضمّن + `js/app.js` غير مُستدعى) أُزيل، والتحميل الأولي ≈ 103 كيلوبايت.

### SEO
- `metadata` و`generateMetadata` لكل صفحة، و`canonical`، وOpen Graph وTwitter Card.
- **بيانات منظمة JSON-LD** (Store / Product / Article / BreadcrumbList) — لم تكن موجودة إطلاقًا.
- `sitemap.xml` و`robots.txt` تلقائيان، وصفحة صنف مستقلة لكل منتج (قابلة للمشاركة والفهرسة).
- لوحة التحكم والسلة وواجهات API مستثناة من الفهرسة.

### الوصولية (كانت 0.82 في Lighthouse القديم)
- إصلاح تباين الألوان (نصوص داكنة على خلفيات فاتحة للشارات).
- تسلسل عناوين صحيح (h1 واحد لكل صفحة، ثم h2 ثم h3).
- تسميات (`label`) لكل حقول الإدخال والقوائم المنسدلة.
- رابط «تجاوز إلى المحتوى» (skip link)، و`aria-label` للتنقل، و`aria-current` للصفحة الحالية.
- منطقة إشعارات حيّة (`aria-live`) لإعلامات قارئ الشاشة.
- وصف `alt` لكل الصور، و`sr-only` للأزرار الأيقونية.

### الوصولية والاستخدام
- الفلترة في المتجر عبر معاملات URL بحث (server-side) — تعمل بدون JavaScript وقابلة للمشاركة.
- صفحات منفصلة بدل صفحة واحدة طويلة، مع مسار تنقل (breadcrumb).
- عرض الأسعار بثلاث عملات (دولار / ريال يمني / ريال سعودي).

## لوحة التحكم

- المسار: `/admin/login`
- لا يوجد أي مسار دخول بدون كلمة مرور.
- كل عملية دخول/خروج/تغيير كلمة مرور/تعديل صنف تُسجَّل في جدول `admin_audit`.
- الصلاحيات مُطبَّقة **على الخادم**: من لا يملك صلاحية «تعديل الأسعار» لا يستطيع تغيير السعر حتى بتعديل الطلب يدويًا.
- تغيير كلمة المرور يُنهي كل الجلسات الأخرى.
- تنبيه دائم إن لم يُغيَّر الحساب كلمة المرور الأولية.
